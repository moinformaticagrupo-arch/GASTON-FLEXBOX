# Práctico 1 – Maquetando con Flexbox | Estudio Norte

## Para abrir
1. Descargá y descomprimí el ZIP.
2. Entrá en la carpeta `Practico1_Flexbox_V3`.
3. Abrí `index.html` con doble clic.

## Archivos incluidos
- `index.html`: estructura de la página.
- `style.css`: diseño visual, Flexbox y adaptación a móviles.
- `app.js`: interacción del menú.
- `README.md`: estas instrucciones.

## Aplicación de Flexbox
- `.nav`: organiza la marca, navegación y botón.
- `.hero-layout`: alinea texto e imagen horizontal y verticalmente.
- `.intro-layout`: distribuye el título y la explicación.
- `.services`: ordena las tarjetas con `flex-wrap` y `gap`.
- `.gallery`: distribuye los proyectos en una galería flexible.
- `.contact-layout` y `.footer-layout`: alinean sus elementos.

## Publicar en GitHub Pages
1. Subí los archivos a la raíz de un repositorio.
2. Entrá en Settings → Pages.
3. En Build and deployment, elegí Deploy from a branch.
4. Seleccioná `main` y `/ (root)`.
5. Guardá y esperá el enlace de publicación.

Las fotografías y fuentes externas necesitan conexión a Internet.
